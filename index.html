Turn an email into a calendar appointment

Copy its subject and plain text into a draft. Review the time and save in Outlook.

Download Create Appointment

Manifest only · Printable installation guide

Before you start

Use a supported Microsoft mailbox in new Outlook for Windows or Outlook on the web with Mailbox API 1.9. Your organization may block custom add-ins; ask its administrator if the installation option is missing. No Node.js or VS Code is needed.

1. Download and extract

Download Create-Appointment-for-Friends.zip from the public download page and extract both files. The ZIP contains only Create-Appointment.xml and this guide.

2. Install in your mailbox

Sign in to the intended mailbox. Open https://aka.ms/olksideload. Choose My add-ins, then Custom Addins > Add a custom add-in > Add from File. Select Create-Appointment.xml and review the prompts.

3. Find and pin the command

Open an ordinary email. Choose Apps > right-click Create Appointment > Pin. If it is missing, refresh Outlook and confirm your mailbox policy permits add-ins. Menu placement can vary by client.

4. Review and save

Click Create Appointment. Review the copied subject and plain-text body. Change date, time, time zone, calendar, location, and online-meeting defaults as needed. Keep attendees empty and choose Save. Cancel discards the draft. Mark sensitivity Private yourself if needed.

What it copies

Plain text only; attachments, images, and formatting are not copied. Outlook may include quoted conversation text. The default is now for 30 minutes. Subjects over 255 characters and bodies over 32,000 characters are rejected. The command opens a draft; it does not save or send it.

Troubleshooting and removal

If nothing opens, check internet access to the download page and retry with an ordinary unprotected email. Errors appear on the original message when Outlook permits notifications. Remove the add-in through My add-ins > Custom Addins > its menu > Remove.

Release status and privacy

Live Outlook testing has not been claimed. Test with a harmless email before relying on this release. There is no analytics or custom email-upload endpoint. Normal Microsoft services and calendar-sharing rules apply. Development source is private; the hosted runtime JavaScript is necessarily public.
