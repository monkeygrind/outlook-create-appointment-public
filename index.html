Before you start

Use a supported Microsoft mailbox and a client with Mailbox API 1.9. These instructions distinguish Outlook on the web, new Outlook for Windows, and classic Outlook for Windows (the desktop or 'thick' client). Your organization may block custom add-ins. No Node.js or VS Code is needed.

1. Download and extract

Download Create-Appointment-for-Friends.zip from the public download page and extract both files: Create-Appointment.xml and START-HERE.pdf. Downloading a new ZIP does not replace an installed add-in.

2. Install - Outlook on the web

In your browser, sign in to the intended Microsoft mailbox and open https://aka.ms/olksideload. Choose My add-ins > Custom Addins > Add a custom add-in > Add from File. Select Create-Appointment.xml and review the prompts. Refresh Outlook on the web afterward.

2a. Install - Windows desktop clients

Classic Outlook: select the intended mailbox, then File > Info > Manage Add-ins. This opens the mailbox's web add-ins dialog in a browser; follow step 2 there. If Manage Add-ins is missing, use the browser link in step 2.
New Outlook: use step 2 in a browser signed into the same mailbox. Close and reopen desktop Outlook afterward. Check Apps or All Apps on an opened email. Do not assume immediate sync: Microsoft says classic Outlook may take up to 24 hours to show a sideloaded add-in. For a different mailbox, repeat installation while signed into that mailbox.

3. Open the command - pinning is optional

Web or new Outlook: select an email, then Apps in the message action bar or More apps on the ribbon > Create Appointment. For pinning, try More apps on the ribbon > right-click Create Appointment > Pin, if offered.
Classic Outlook: set View > Reading Pane to Right or Bottom. Select an email, then Home > All Apps (or Apps) > Create Appointment; if its button is already on the ribbon, click it there. If no Pin menu appears, use Apps > Create Appointment each time. This add-in does not provide a Quick Steps action.

4. Review and save

Review the copied subject and plain-text body. Change date, time, time zone, calendar, location, and online-meeting defaults as needed. Keep attendees empty and choose Save (or Save & Close, depending on the client). Cancel discards the draft. Set sensitivity Private yourself if needed.

Updating or replacing an existing installation

A new download does not auto-replace the installed XML. If you installed an older manifest, especially one using the former source-repository hosting URL, download and extract the current ZIP. Open the same mailbox's Add-Ins for Outlook dialog (step 2 or 2a). Under My add-ins > Custom Addins, open Create Appointment's menu > Remove. Then Add a custom add-in > Add from File and select the new Create-Appointment.xml. Refresh web Outlook and restart desktop Outlook; find or pin the command again. Reinstall whenever the manifest changes. Changes only to hosted HTML/JavaScript normally load from the existing URLs without reinstalling, subject to caching. This guide-only update leaves the manifest unchanged, so existing installations using the public hosting URL do not need reinstalling.

Quick Steps and Reply with Meeting

Quick Steps and Reply all by meeting are Outlook facilities; this add-in does not install or change them. A Quick Step you configured to reply with a meeting invokes Outlook's meeting workflow, not Create Appointment. There is no Quick Steps shortcut supplied for this command; use Apps or its ribbon button. Pin and Unpin actions within Quick Steps apply to messages, not add-in buttons.

What it copies

Plain text only; attachments, images, and formatting are not copied. Outlook may include quoted conversation text. The default is now for 30 minutes. Subjects over 255 characters and bodies over 32,000 characters are rejected. The command opens a draft; it does not save or send it.

Troubleshooting and removal

If desktop Outlook does not show the add-in, verify that the web and desktop clients use the same mailbox, restart desktop Outlook, and allow for the classic Outlook caching delay. Confirm installation in My add-ins before attempting replacement. If no draft opens, check internet access and try an ordinary unprotected email. Errors appear on the original message when notifications are available. Remove through My add-ins > Custom Addins > Create Appointment's menu > Remove.

Release status and privacy

Live operation in each Outlook client still needs verification; screenshots show menu placement, not a completed appointment test. Try a harmless email before relying on this release. No analytics or custom email-upload endpoint is included. Normal Microsoft services and calendar-sharing rules apply. Development source is private; hosted runtime JavaScript is public.
